# WhatZaapp2
Utilizando FireBase, JavaScript e ReactNative, é um aplicativo aonde salva as mensagens de cada usuário, podendo trocar entre eles e excluir os chats, com integração e validação via banco, bem como as mensagens enviadas podem ser acessadas individualmente independente do acesso ou conexão. Para mais detalhes acesse a pasta "Rodando", e para conectar você mesmo utilize o arquivo "Tutorial.txt"
